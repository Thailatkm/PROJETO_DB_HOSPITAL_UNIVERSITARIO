# PROJETO_DB_HOSPITAL_UNIVERSITARIO

# Sistema de Gestão Hospitalar Universitário

Participei do desenvolvimento e documentação do projeto de Sistema de Gestão do Hospital Universitário, contribuindo na modelagem do banco de dados e na elaboração da documentação técnica utilizando metodologias como IDEF0, MER e DER.

O desenvolvimento SQL foi realizado utilizando o SGBD Oracle.
